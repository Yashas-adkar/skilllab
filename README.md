# 🤖 SkillLab — AI Mock Interview Platform

SkillLab is an AI-powered interview preparation platform designed to help students and aspiring developers prepare for technical interviews through a structured and interactive experience.

## 🚀 Features

* 🔐 Email & Google Authentication
* 👤 Personal Profile & Skills
* 🎯 Career Stream Selection
* 📄 AI Resume Analysis
* 🧠 Aptitude Assessment with 10 Questions
* 💻 Coding & Problem-Solving Assessment
* 🤖 AI Technical Mock Interview
* 🎙️ Voice & Text Interview
* 📊 Performance & Interview Readiness Evaluation
* 💬 AI Help Chatbot
* 🌓 Light & Dark Mode
* 📈 Assessment History

## 🔄 Interview Process

```text
Sign Up / Sign In
       ↓
Profile & Career Stream
       ↓
Resume Analysis
       ↓
Aptitude Test
       ↓
Coding & Problem Solving
       ↓
AI Mock Interview
       ↓
Final Evaluation
       ↓
Personalized Recommendations
```

## 🧠 AI Mock Interview

The AI interviewer analyzes user responses and can:

* Ask technical and follow-up questions
* Evaluate answer quality
* Identify incorrect or incomplete answers
* Adapt questions based on performance
* Support text and voice interaction
* Provide personalized feedback

## 💬 AI Help Assistant

The built-in chatbot helps users understand and navigate the platform. Users can ask natural questions about features, profile fields, interview stages, assessments, results, and other available functionality.

## 🛠️ Tech Stack

* **Frontend:** React / Next.js / TypeScript
* **Authentication & Database:** Firebase
* **AI:** AI-powered APIs
* **Voice:** Speech processing APIs
* **Coding:** Secure code execution service
* **Development:** VS Code, Antigravity, Git & GitHub
* **Deployment:** Netlify

## 🎯 Purpose

SkillLab brings resume preparation, aptitude practice, coding assessment, and AI-powered interviews together in one platform to help users understand their strengths and identify areas for improvement.
